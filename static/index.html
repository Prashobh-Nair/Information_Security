Exercise 12: Realize for HTTP, HTTPS, DNS, ARP, and FTP

Comprehensive protocol verification matrix documenting transport ports, payload encryption states, and Layer 2–7 dissection.

ICMP Internet Control Message Protocol
Network Layer (L3) diagnostic protocol for reachability probes without port numbers.
Type 8: Echo Request • Type 0: Echo Reply • RFC: 792
ARP Address Resolution Protocol
Layer 2 broadcast protocol resolving IP addresses to physical 48-bit MAC addresses.
Opcode 1: Who has IP? • Opcode 2: IP is at MAC • RFC: 826
DNS Domain Name System
Application Layer name resolution translating human hostnames into IP routing addresses.
Transport: UDP Port 53 • Query: Type A (IPv4) • RFC: 1035
HTTP Hypertext Transfer Protocol
Cleartext application protocol transmitting forms and passwords in plain ASCII text.
Transport: TCP Port 80 / 5000 • Security: CWE-319 Cleartext Leak • RFC: 2616
HTTPS HTTP Secure (TLS 1.3)
Cryptographic communication channel wrapping HTTP in TLS 1.3 AES-256 session keys.
Transport: TCP Port 443 / 5443 • Cipher: AES-256-GCM • RFC: 8446
FTP File Transfer Protocol
Legacy unencrypted file transfer protocol transmitting commands and passwords in cleartext.
Transport: TCP Port 21 (Control) • Authentication: USER / PASS Cleartext • RFC: 959
